# Android beta testing

The download is an ARM64 Android beta, version 0.2.3-beta.1+5, for Android 7.0 / API 24 or later. It installs separately from the production package. ARM64 support does not qualify every device, installation method, or Android version.

Use synthetic test records. Try KJV reading and its download, save a passage, make a reading plan, and create a Today task with an optional time block and priority. Restart the app and confirm your records remain. Task editing is best tested in portrait; landscape editing with the keyboard has known clipping limits.

Focus/Guard, reminders, additional translations, and cloud/accountability are deferred. The APK still declares an unfinished accessibility test service that may appear as "New Man whole-app test". Do not enable it in Android Accessibility settings.

Bounded checks cover selected task and Scripture flows. They do not establish broad device coverage, airplane-mode reading, large-text or landscape quality, production upgrades, or full accessibility/security qualification. This source handoff does not make a new installer/launcher qualification claim.

KJV text is downloaded directly from eBible when requested. See the third-party notices for provenance and the unresolved UK distribution caveat.

Do not uninstall an existing app to work around signing or install problems. Do not post private notes, account details, phone identifiers, credentials, or private screenshots in public issues. Feedback can use the repository's Issues page with the app version, Android/device model, and reproducible steps using synthetic data.
